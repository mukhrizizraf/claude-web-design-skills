# Claude Web Design Skills

Which Claude Code skill to use for each design, UI and motion job, and what to say to trigger it.

**Live cheat sheet:** https://mukhrizizraf.github.io/claude-web-design-skills/

## What's here

| File | What it is |
|---|---|
| `index.html` | The Design Skill Router cheat sheet: jobs grouped by stage, a phrase to say for each, the skill it triggers, and every Impeccable command. Searchable. |
| `CLAUDE.md` | The routing table Claude Code follows, so it picks one skill per job instead of guessing between overlapping ones. |

## Use the routing table

Copy `CLAUDE.md` to `~/.claude/CLAUDE.md` (on Windows: `C:\Users\<you>\.claude\CLAUDE.md`). Claude Code reads it at the start of every session, in every project. If you already have that file, paste the table into it instead of replacing it.

## Skills it routes to

- [Impeccable](https://github.com/pbakaus/impeccable)
- [Emil Kowalski's skills](https://github.com/emilkowalski/skills): animate, apple-design, break-ui, mobile-native and more
- [diagram-design](https://github.com/cathrynlavery/diagram-design)
- [LottieFiles motion-design](https://github.com/LottieFiles/motion-design-skill)
- GSAP and Three.js skills, genjutsu (`paint`, `cast`, `bunshin`), `taste`, `design-dna`, `ui-ux-pro-max` and others

The table only helps for skills you have installed.
