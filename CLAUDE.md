# Design / UI / motion skill routing

Many installed skills overlap. For any design, UI or motion request, pick ONE default skill from this table (plus a library skill like gsap-* or threejs-* if the code uses it), say in one line which skill you're using and why, then proceed. Don't stack overlapping skills. If the user names a skill, use that one.

| Job | Default skill |
|---|---|
| Copy the look of a site (URL given) | taste |
| Analyze screenshots/images into a style | design-dna |
| No reference yet, need examples | design-inspiration |
| Pick palette / font pairing / style | ui-ux-pro-max |
| Plan UX/UI before coding | impeccable (shape) |
| Build a page, component or feature | impeccable |
| Full visual identity + design system | paint |
| Whole multi-page site, full pipeline | bunshin (expensive; only when the user asks for the full pipeline) |
| Improve existing UI | impeccable verb: polish, bolder, quieter, colorize, typeset, layout, clarify, distill, adapt, onboard, delight, overdrive |
| UX critique | impeccable (critique) |
| Technical audit (a11y, perf, responsive) | impeccable (audit) |
| Principles audit leading to a plan | claude-mem:design-is |
| Stress-test with worst-case data | break-ui |
| Production hardening (errors, i18n, overflow) | impeccable (harden) |
| Web app should feel native on phones | mobile-native |
| Apple-style springs, gestures, sheets | apple-design |
| Build one animation / transition | animate (+ gsap-* if using GSAP) |
| Signature wow-factor interaction | cast |
| "What should animate here?" | find-animation-opportunities |
| Audit all motion in a codebase | improve-animations |
| Review motion in a diff | review-animations |
| Janky / dropped frames | animation-performance |
| Name a motion effect | animation-vocabulary |
| Motion system: timing, easing, choreography | motion-design |
| Scroll-driven animation | gsap-scrolltrigger |
| 3D scene | threejs-* (react-three-fiber for React) |

| Choose a library | pick-ui-library |
| Several variants to compare | prototype |

| Diagram or chart | diagram-design |
| Poster / static art | canvas-design |
| Generative art | algorithmic-art |
| Theme slides / docs / artifacts | theme-factory |
